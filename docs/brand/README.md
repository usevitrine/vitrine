# Vitrine's logo and images

- `vitrine-icon.svg` - the mark: the letter V cut like a crystal (mauve #cba6f7 to pink #f5c2e7 on #1e1e2e). The app's
  icons are made from it (web/public; see docs/ui/design-language.md, "The logo").
- `usevitrine-avatar.png` (1024x1024) - the GitHub account's picture (the mark inside the circle GitHub crops to).
- `vitrine-social.png`, `vitrine-plugins-social.png` (1280x640) - the repositories' social preview images
  (Settings > General > Social preview on GitHub).
